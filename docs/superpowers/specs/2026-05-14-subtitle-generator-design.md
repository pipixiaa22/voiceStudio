# SRT 字幕生成器设计

## 概述

将一段中文文字自动分段并生成 SRT 字幕文件，用于导入剪映 (CapCut)。

## 输入

- **文件模式**：`uv run main.py input.txt`
- **交互模式**：`uv run main.py`，粘贴文字后按 `Ctrl+D` 结束

## 分段逻辑

1. 按 `。？！` 等句末标点拆分为句子
2. 超过 `--max-chars`（默认 20）的句子，在 `，、；：` 处进一步拆分
3. 仍然超长则按字数强制截断

## 时间计算

- 语速：`--speed`（默认 5 字/秒）
- 每段时长 = 字数 / 语速
- 时间戳从 0 开始累加

## 输出

- SRT 格式文件，默认 `output.srt`，可通过 `-o` 指定
- 格式：序号 + 时间戳 + 字幕文本

## 命令行参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `input_file` | 无 | 输入文件路径（可选） |
| `--speed` | 5 | 语速（字/秒） |
| `--max-chars` | 20 | 每段最大字数 |
| `-o` | output.srt | 输出文件路径 |

## 依赖

- 零外部依赖，纯 Python 标准库
- `argparse` 处理命令行参数
- `re` 处理正则匹配
- `sys.stdin` 处理交互输入
