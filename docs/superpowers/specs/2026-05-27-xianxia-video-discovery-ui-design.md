# 修仙短视频热点采集前端 UI 设计方案

## 设计目标

新增“热点采集”前端功能，用于把热门视频网站中的修仙小说短视频样本转化为可生产的原创脚本和视频生成参数。

页面不做营销式展示，而是做成高效率创作工作台：

```text
找热点
-> 判断是否值得参考
-> 分析标题/钩子/结构/节奏
-> 生成原创脚本
-> 导入文本库
-> 进入现有视频生成向导
```

这个 UI 应该和当前“墨 · 影”风格一致：浅纸色背景、黑白主按钮、低饱和边框、清晰的信息密度、克制动效。它要服务长期使用，而不是只让第一次打开时觉得新鲜。

## 当前前端基础

现有项目使用：

- Vue 3 + Vite。
- Ant Design Vue。
- Pinia store。
- `web/src/styles/theme.css` 中已有完整主题变量。
- `web/src/App.vue` 只有顶部导航和设置入口。
- `web/src/views/TextList.vue` 已经形成左侧文件夹、中间文本列表、右侧详情预览的工作台布局。
- `web/src/components/video/VideoGenerateModal.vue` 已经是六步视频生成向导。

热点采集页面应复用这些模式：

- 页面骨架延续 `TextList.vue` 的多栏工作台。
- 操作按钮延续当前 `a-button` 和图标按钮风格。
- 列表行、标签、空状态、loading、错误态延续已有 Ant Design Vue + 主题变量。
- 不引入全新的视觉体系，不使用大面积彩色渐变。

## 信息架构

新增一级导航：“热点采集”。

路由建议：

```text
/discovery
```

页面由四个主要区域组成：

```text
┌─────────────────────────────────────────────────────────────┐
│ 顶部检索栏：平台 / 关键词 / 时间范围 / 时长 / 排序 / 搜索     │
├──────────────┬───────────────────────────┬──────────────────┤
│ 左侧任务栏    │ 中间候选列表               │ 右侧分析面板       │
│ 关键词包      │ 视频卡片/表格              │ 热度/结构/脚本     │
│ 历史查询      │ 评分/封面/指标             │ 导入/生成视频      │
│ 收藏夹        │ 批量操作                   │ 来源追溯           │
└──────────────┴───────────────────────────┴──────────────────┘
```

桌面端默认三栏。移动端改为上下分区：

```text
检索栏
-> 查询/关键词折叠面板
-> 结果列表
-> 点击候选项后打开底部抽屉显示分析
```

## 用户使用逻辑

### 主流程：从热点到视频

1. 用户进入“热点采集”。
2. 选择平台：全部、手动链接、YouTube、抖音、快手、B 站。
3. 输入关键词，如“修仙小说 一张图”、“仙帝重生 有声小说”。
4. 点击“搜索热点”。
5. 系统展示候选列表，并显示相关性评分、热度评分和形态判断。
6. 用户选中一条候选视频。
7. 右侧分析面板展示来源、标题、作者、热度指标、命中原因。
8. 用户点击“分析结构”。
9. 系统生成标题套路、开头钩子、剧情骨架、字幕节奏、视频参数建议。
10. 用户点击“生成原创脚本”。
11. 右侧出现脚本草稿预览，用户可局部编辑标题和正文。
12. 用户点击“导入文本库”。
13. 系统创建 `Text`，自动加标签：`修仙`、`热点参考`、平台名、`原创改写`。
14. 用户可以选择：
    - “去编辑”：跳转 `TextEdit`。
    - “生成视频”：打开现有 `VideoGenerateModal`，带入推荐模板、声线、字幕参数和来源上下文。

### 手动链接流程

适用于国内平台 API 不可用或用户已经看到具体样本。

1. 用户切换到“手动链接”。
2. 粘贴视频链接。
3. 点击“解析链接”。
4. 系统识别平台并保存来源。
5. 如果只能拿到基础信息，列表显示“元数据有限”状态。
6. 用户仍可手动填写标题、作者、描述或上传授权截图/视频。
7. 后续走同样的“分析结构 -> 生成原创脚本 -> 导入文本库”流程。

### 收藏与复盘流程

1. 用户在候选列表中点击收藏图标。
2. 左侧“收藏夹”计数增加。
3. 收藏项保留原平台链接、评分、分析结果和脚本草稿状态。
4. 用户以后可以按平台、关键词、是否已生成脚本筛选。

## 页面布局细节

### 顶部检索栏

位置：页面顶部，吸附在内容区域内，不覆盖全局导航。

内容：

- 平台选择：`a-segmented` 或紧凑 `a-select`。
- 关键词输入：支持普通关键词和关键词包。
- 时间范围：最近 7 天、30 天、90 天、全部。
- 时长筛选：30 秒以内、30 秒到 2 分钟、2 到 8 分钟。
- 排序：综合推荐、最新、热度、相关性。
- 主按钮：`搜索热点`。
- 次按钮：`解析链接`。

交互：

- 按 Enter 触发搜索。
- 搜索中按钮显示 loading。
- 关键词为空时禁用搜索，并在输入框下方显示轻提示。
- 搜索完成后显示“本次找到 N 条候选”。

视觉：

- 使用 `var(--surface)` 背景。
- 底部 1px `var(--surface-border)` 分割线。
- 控件高度统一 34-36px。
- 搜索按钮使用当前黑色主按钮。

### 左侧任务栏

宽度：260px。可以折叠，复用文本库侧栏的折叠逻辑。

分组：

1. 关键词包
   - 默认：修仙、玄幻、仙帝重生、废柴逆袭、宗门、女帝、系统流。
   - 点击关键词包后自动填入检索栏。
   - 支持用户新增自定义关键词包。

2. 历史查询
   - 显示最近 20 次查询。
   - 每条显示关键词、平台、结果数、时间。
   - 点击可恢复查询条件。

3. 收藏夹
   - 全部收藏。
   - 已分析。
   - 已生成脚本。
   - 已导入文本库。

空状态：

- 没有历史查询时显示“搜索一次后会出现在这里”。
- 没有收藏时显示“收藏值得复盘的样本”。

### 中间候选列表

这是页面的信息核心。建议使用“紧凑视频样本卡片列表”，不是传统大卡片瀑布流。

每个候选项显示：

- 封面缩略图，固定 72x112，竖屏比例裁切。
- 平台标识。
- 标题，两行截断。
- 作者。
- 发布时间。
- 时长。
- 播放、点赞、评论、分享指标。
- `修仙相关` 分数。
- `热度` 分数。
- `单图字幕语音` 形态分数。
- 状态标签：未分析、已分析、已生成脚本、已导入文本。
- 操作按钮：收藏、打开原链接、分析。

列表排序：

- 默认按综合分排序。
- 综合分 = 修仙相关 40% + 热度 35% + 单图形态 25%。
- 用户切换排序后保留筛选条件。

选中状态：

- 当前选中项使用 `var(--surface-border-strong)` 边框和浅底色。
- 右侧面板同步显示对应分析。

批量操作：

- 顶部提供复选框和批量收藏。
- 第一阶段不提供批量生成脚本，避免误生成大量同质内容。

### 右侧分析面板

宽度：380-440px。固定在右侧，内容内部滚动。

右侧面板分为 5 个标签页：

```text
概览 | 热点结构 | 原创脚本 | 视频建议 | 来源记录
```

#### 概览

展示：

- 平台、作者、发布时间、原链接。
- 标题。
- 核心指标：播放、点赞、评论、分享。
- 三个评分仪表：修仙相关、热度、单图形态。
- 命中原因。

主操作：

- `分析结构`
- `收藏`
- `打开原链接`

#### 热点结构

展示系统分析出的可参考结构：

- 标题套路。
- 前 3 秒钩子。
- 冲突来源。
- 主角设定。
- 爽点设计。
- 悬念断点。
- 字幕节奏。

设计方式：

- 用短标签和分段说明，不用长篇正文。
- 每个结构块可以复制。
- 分析失败时显示失败原因和“重新分析”。

#### 原创脚本

展示原创脚本生成器：

- 标题输入框。
- 篇幅选择：短 30-60 秒、中 1-2 分钟、长 3-5 分钟。
- 风格选择：热血、冷峻、爽文、悬疑、女频。
- 生成按钮：`生成原创脚本`。
- 脚本文本预览区。
- 字数统计。
- “导入文本库”主按钮。

导入成功状态：

- 显示 `已导入文本 #ID`。
- 操作按钮变为 `去编辑` 和 `生成视频`。

#### 视频建议

展示导入视频生成向导时会预填的参数：

- 推荐模板：`修仙旁白` / `角色独白` / `战斗转场`。
- 推荐声线：沉稳男声、清冷女声、少年感男声等。
- 推荐字幕长度：16-20 字。
- 推荐 BGM 氛围：低沉、紧张、空灵。
- 推荐场景图关键词：云海山门、破败宗门、雷劫、古殿、剑修背影。

操作：

- `应用到视频生成`。
- 如果尚未导入文本，按钮置灰并提示先生成脚本。

#### 来源记录

展示：

- 原始平台链接。
- 采集时间。
- 查询关键词。
- 连接器名称。
- 原始元数据摘要。
- 授权素材说明。

目的：

- 让用户知道脚本灵感来自哪里。
- 方便后续删除、审查和复盘。

## 样式规范

### 色彩

沿用当前主题：

```css
--paper: #f7f7f5;
--paper-soft: #fbfbfa;
--surface: #ffffff;
--surface-muted: #f1f1ee;
--surface-border: #deddd8;
--surface-border-strong: #c7c6c0;
--text-primary: #111111;
--text-secondary: #4b4a47;
--text-muted: #77736c;
```

评分色只作为小面积状态色，不改变整体黑白基调：

```css
--score-high: #2f6f4e;
--score-mid: #8a6a18;
--score-low: #9a3f3f;
--source-youtube: #b42318;
--source-bilibili: #1877a8;
--source-douyin: #111111;
--source-kuaishou: #b85c00;
```

使用规则：

- 主按钮仍用黑色。
- 平台色只用于小标签或图标点。
- 评分色只用于 12px 标签、进度条或小圆点。
- 不使用大面积渐变和高饱和背景。

### 字体与字号

沿用 `--font-body` 和 `--font-display`。

建议字号：

- 页面标题：24px / 650。
- 区块标题：14px / 620。
- 列表标题：14px / 620，两行截断。
- 正文说明：13px / 1.7。
- 元数据：11-12px。
- 分数：12px / 650。

### 间距与尺寸

- 页面最小高度：`calc(100vh - 64px)`。
- 左侧栏宽度：260px。
- 右侧栏宽度：400px，最小 360px。
- 候选项高度：128-148px。
- 封面尺寸：72x112。
- 控件高度：34-36px。
- 卡片圆角：8px，跟当前 `--radius-md` 对齐。
- 面板之间使用 1px 边框，不使用嵌套卡片。

### 图标

项目当前多使用内联 SVG。实现时可以继续使用内联 SVG，或引入已有图标库后统一替换。

建议图标语义：

- 搜索：放大镜。
- 链接解析：链条。
- 收藏：星标。
- 打开原链接：外链箭头。
- 分析：节点/雷达。
- 导入文本：文件加号。
- 生成视频：视频矩形。
- 设置：齿轮。

不要使用 emoji 作为正式图标；已有视频模板组件里的 emoji 后续也可以一并替换为线性图标。

## 状态设计

### 初始空状态

中间区域显示：

```text
还没有热点样本
选择平台并输入关键词，或粘贴一个视频链接开始分析。
```

操作：

- `试试：修仙小说 一张图`
- `粘贴链接`

### 搜索中

- 顶部按钮 loading。
- 中间列表显示 6 条骨架屏。
- 右侧面板显示“等待选择样本”。

### 搜索无结果

显示：

```text
没有找到匹配样本
可以放宽时间范围、减少关键词，或使用手动链接导入。
```

操作：

- `清空筛选`
- `解析链接`

### 分析中

右侧面板显示步骤进度：

```text
读取元数据
计算相关性
识别视频形态
提取热点结构
生成原创建议
```

每步用简单状态点，不做复杂进度条。

### 分析失败

显示：

- 失败原因。
- 是否可重试。
- 是否需要配置平台 Key。
- 是否因为平台能力未开放。

操作：

- `重新分析`
- `查看设置`
- `改为手动填写`

### 导入成功

右侧原创脚本页显示成功条：

```text
已导入文本库：开局被逐出宗门，我在后山觉醒万古剑骨
```

操作：

- `去编辑`
- `生成视频`

## 与现有视频生成向导的连接

`VideoGenerateModal.vue` 建议增加可选 `prefill` prop：

```js
{
  template_key: 'xianxia_narration',
  voice_description: '沉稳、有故事感的男声，节奏略慢，适合修仙旁白',
  subtitle_options: {
    max_chars: 18,
    gap: 0.3
  },
  audio_options: {
    bgm_enabled: true,
    bgm_volume: 0.16,
    ambient_enabled: true,
    ambient_key: 'wind'
  },
  scene_keywords: ['云海山门', '雷劫', '古殿', '剑修背影'],
  source_context: {
    discovery_item_id: 123,
    platform: 'youtube',
    source_url: 'https://www.youtube.com/watch?v=abc123xyz00'
  }
}
```

用户点击“生成视频”后的行为：

1. 如果脚本未导入，先弹出确认：“需要先导入文本库再生成视频”。
2. 如果脚本已导入，打开现有 `VideoGenerateModal`。
3. 模板步骤默认选中推荐模板。
4. 音色步骤预填推荐声线。
5. 音频步骤预填 BGM/环境音建议。
6. 预览步骤显示“灵感来源”摘要，但不把平台素材打入导出包。

## 推荐交互细节

### 快捷操作

- `Enter`：执行搜索。
- `⌘K`：聚焦关键词输入，和文本库搜索保持一致。
- `J / K`：在结果列表上下移动。
- `A`：分析当前选中项。
- `S`：收藏当前选中项。

快捷键可以先写在代码里，不必在界面大面积说明。

### 防误用提示

当用户尝试下载或复用平台封面时，显示确认：

```text
请确认你拥有该素材的使用权。默认推荐只把它作为灵感来源，不放入视频素材包。
```

当脚本相似度过高时，显示：

```text
当前脚本与参考标题/结构接近，建议重新生成或修改人物、冲突和世界观。
```

### 可编辑但不打断

生成原创脚本后，不强制跳转编辑页。右侧直接提供轻量编辑：

- 标题可改。
- 正文可改。
- 标签可改。
- 文件夹可选。

用户确认后再导入文本库。

## 数据展示规则

### 热度指标

不同平台指标字段不一致，统一展示时使用可用字段：

```text
播放 12.4w
点赞 8,230
评论 312
分享 86
```

缺失字段显示 `--`，不要显示 0，避免误导。

### 评分显示

三个评分都使用 0-100：

- 80-100：高。
- 50-79：中。
- 0-49：低。

视觉：

- 小标签：`相关 86`。
- 右侧概览用细进度条。
- 鼠标悬停显示命中原因。

### 平台权限状态

顶部或左侧显示 Connector 状态：

- 已启用。
- 未配置 Key。
- 需要授权。
- 能力未开放。
- 配额不足。

状态提示要直白，不要让用户以为是系统坏了。

## 响应式设计

### 桌面端 >= 1200px

- 三栏布局。
- 左侧 260px，中间自适应，右侧 400px。
- 搜索栏完整展示。

### 平板 768px - 1199px

- 左侧栏折叠为按钮。
- 中间列表 + 右侧面板双栏。
- 搜索栏第二行换行。

### 手机 < 768px

- 单列布局。
- 搜索条件变成折叠面板。
- 候选列表全宽。
- 分析面板使用 `a-drawer` 从底部或右侧打开。
- 操作按钮固定在 drawer 底部。

## 可访问性

- 所有图标按钮必须有 `a-tooltip` 或 `aria-label`。
- 列表项可键盘选中。
- 评分不能只依赖颜色，必须显示数字。
- loading 和错误状态必须有文本。
- 原链接打开使用新窗口，并在按钮文案或 tooltip 中说明。
- 抽屉关闭后焦点回到原候选项。

## 文案规范

页面文案要短，像工具，不像教程。

推荐文案：

- 页面标题：`热点采集`
- 副标题：`从热门样本提取结构，生成自己的修仙短视频脚本`
- 搜索按钮：`搜索热点`
- 链接按钮：`解析链接`
- 分析按钮：`分析结构`
- 脚本按钮：`生成原创脚本`
- 导入按钮：`导入文本库`
- 视频按钮：`生成视频`

风险提示文案：

```text
默认只保存来源和分析结果，不下载原视频、原音频或原字幕。
```

请确认你拥有素材使用权。未授权素材只作为灵感来源。

## 验收标准

1. 用户能从导航进入“热点采集”。
2. 用户能输入关键词或粘贴链接并看到结果状态。
3. 结果列表能清楚展示平台、标题、作者、热度、相关性和形态评分。
4. 选中结果后，右侧能展示概览和分析结果。
5. 用户能生成原创脚本，并在导入前编辑标题和正文。
6. 导入文本库后能跳转编辑页或打开视频生成向导。
7. 视频生成向导能读取推荐模板、声线、字幕和音频参数。
8. 空状态、加载态、失败态、未配置平台 Key 都有明确反馈。
9. 页面在桌面、平板、手机三种宽度下无文字重叠和按钮溢出。
10. 默认不下载第三方原视频、音频、字幕或封面进入素材包。

## 总结

“热点采集”页面应是一个创作前置工作台，不是爬虫控制台。它的体验重点是帮助用户快速判断样本价值，抽象爆款结构，生成原创脚本，并自然流入现有文本库和视频生成流程。

推荐视觉方向是“冷静、密集、可复盘”：延续当前黑白纸面主题，用少量平台色和评分色表达状态，不做花哨装饰。这样的设计更适合长期批量创作，也能让功能和现有字幕/视频工作流像同一个产品。
