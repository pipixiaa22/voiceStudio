# 音色档案 UI 文档

## 设计目标

音色档案 UI 的目标不是展示很多参数，而是帮助用户快速回答三个问题：

1. 我现在选的是哪个声音？
2. 这个声音适合什么场景？
3. 我能不能放心用它生成整篇语音？

界面要延续当前“墨 · 影”的黑白克制风格，重点放在结构、密度和状态表达上。

## 信息架构

语音合成界面中，音色相关区域分三层：

```text
当前音色
预设/自定义列表
创建与编辑抽屉
```

默认视图只显示“当前音色”和一个下拉选择，不展开全部配置。

## 当前音色卡片

位置：语音合成弹窗的“音色档案”步骤顶部。

内容：

```text
温柔叙述女声                     系统预设
清澈、温和、语速中慢，适合知识类和情感类短视频旁白。

语速 中慢 · 情绪 温和 · 普通话
[切换音色] [生成试听]
```

视觉：

- 白底或 `paper-soft` 背景。
- 1px 边框。
- 8px 圆角。
- 标题 15-16px，说明 13px。
- 标签使用轻量灰底，不使用彩色标签。

## 音色选择器

建议用弹出层或抽屉，而不是普通 select。普通 select 无法承载描述、标签、预设分组和创建入口。

结构：

```text
搜索音色...

系统预设
┌ 温柔叙述女声      女声 · 中慢 · 温和 ┐
└ 沉稳纪录片男声    男声 · 慢速 · 厚重 ┘

我的音色
┌ 我的课程旁白      女声 · 中速 · 清晰 ┐
└ 品牌广告声线      男声 · 中速 · 有力 ┘

[新建音色]
```

筛选：

- 全部
- 系统预设
- 我的音色
- 最近使用

搜索字段匹配：

- 名称
- 描述
- 场景
- 性别
- 情绪

## 系统预设展示

预设建议 8 个以内，避免选择困难。

建议初始预设：

| 名称 | 场景 | 风格 |
|------|------|------|
| 温柔叙述女声 | 情感、知识、生活方式 | 清澈、温和、中慢速 |
| 清晰课程女声 | 教程、课程、讲解 | 清晰、稳定、中速 |
| 沉稳纪录片男声 | 纪录片、历史、深度内容 | 低沉、克制、慢速 |
| 干净新闻男声 | 新闻、资讯、科技播报 | 清楚、理性、中速 |
| 活力短视频女声 | 种草、快节奏口播 | 明亮、轻快、中高速 |
| 治愈故事女声 | 睡前故事、情绪内容 | 柔和、缓慢、放松 |
| 专业商务男声 | 企业介绍、产品说明 | 稳重、清晰、中速 |
| 自然朋友感女声 | vlog、日常分享 | 自然、亲近、中速 |

卡片内不直接展示完整 prompt，只展示人能理解的摘要。

## 创建音色抽屉

打开方式：

- 音色选择器底部 `新建音色`
- 当前音色卡片右上角 `复制为我的音色`

抽屉宽度：

- 桌面端 480px。
- 小屏全屏。

表单结构：

```text
基础信息
- 音色名称
- 使用场景

声音特征
- 性别/年龄感
- 语速
- 情绪
- 音色质感
- 口音

描述
- 我想要的声音
- 我不想要的声音

底部
[取消] [保存并试听]
```

## 表单控件建议

### 性别/年龄感

使用 segmented control：

```text
女声 / 男声 / 中性
年轻 / 成熟 / 年长
```

### 语速

使用单选或 segmented control：

```text
慢 / 中慢 / 中速 / 中快 / 快
```

### 情绪

使用标签选择：

```text
温和 / 稳重 / 轻快 / 克制 / 治愈 / 有力 / 自然 / 专业
```

### 场景

使用 select：

```text
短视频旁白 / 课程讲解 / 故事朗读 / 新闻资讯 / 商务介绍 / 广告口播 / vlog
```

### 自由描述

使用 textarea，占 3-5 行。

占位文案：

```text
例如：像一位耐心的中文课程老师，咬字清晰，语气自然，不要太像播音腔。
```

## 试听区域

试听区应该在保存后立刻出现。

```text
试听文案
今天我们来聊一个很实用的方法。它听起来简单，但真正做好并不容易。你可能会问，第一步应该从哪里开始？

[生成试听]
[audio player]
[确认使用这个音色]
```

如果试听失败：

```text
试听生成失败
请检查 API Key 或稍后重试。
[重试]
```

## 状态表达

| 状态 | UI 表达 |
|------|---------|
| 系统预设 | 小标签 `系统预设` |
| 自定义 | 小标签 `我的音色` |
| 当前选中 | 左侧黑色竖线或深色边框 |
| 已试听确认 | 小标签 `已确认` |
| 未试听 | 小标签 `待试听` |
| 停用 | 降低透明度，隐藏在默认列表外 |

## 主流程中的表现

语音合成主界面不要展示完整音色表单。只展示：

```text
音色档案
温柔叙述女声     已确认
清澈、温和、语速中慢，适合知识类和情感类短视频旁白。

[切换] [试听]
```

只有用户点击 `编辑` 或 `新建` 时，才进入详细配置。

## 高级信息折叠

canonical prompt、negative prompt、provider、model 这些技术字段默认折叠。

折叠标题：

```text
高级提示词
```

展开后显示：

- 标准化音色提示词
- 负向约束
- 供应商
- 模型

这对调试有帮助，但不应该暴露在默认主路径中。

## 移动端适配

小屏下：

- 音色选择器改为全屏抽屉。
- 预设卡片单列。
- 表单控件每行一个。
- 底部保存按钮 sticky。

## 视觉原则

1. 一个页面只突出一个主要操作。
2. 不用大面积色彩区分音色，避免破坏当前黑白主题。
3. 用标签、边框、字重和间距建立层级。
4. 音频播放器只在试听区或当前语音块展示，不在每条字幕下铺开。
5. 预设名称要像产品功能，不要像模型 prompt。

## 推荐默认主按钮

创建音色抽屉中：

```text
保存并试听
```

语音合成主界面中：

```text
生成同步包
```

不要同时出现多个同等级黑色主按钮。
