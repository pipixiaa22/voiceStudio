# 剧情续写模块前端 UI 布局规划

## 设计目标

剧情续写模块的前端应是一个 **长篇小说创作工作台**，首屏直接进入可操作界面，而不是介绍页。

核心体验：

- 左侧管理工程、大纲和章节。
- 中间专注写作与 AI 续写。
- 右侧管理生成参数、版本、人物和事件上下文。
- 图谱作为独立工作区，可编辑人物关系和事件因果。
- 用户始终能看到“当前写到哪里、AI 基于什么生成、哪些设定会被更新”。

## 顶层导航

在现有应用导航中新增：

- `剧情续写`

路由：

- `/novels`：小说工程列表
- `/novels/:id`：小说创作工作台

## 页面一：小说工程列表

文件建议：

- `web/src/views/NovelProjectList.vue`

### 页面结构

```
┌─────────────────────────────────────────────────────┐
│ 顶部工具栏：标题 / 新建工程 / 类型筛选 / 搜索        │
├─────────────────────────────────────────────────────┤
│ 工程表格                                             │
│ 标题 | 类型 | 进度 | 字数 | 最近章节 | 更新时间 | 操作 │
└─────────────────────────────────────────────────────┘
```

### 工程表格字段

- 小说标题
- 类型
- 当前章节进度：`28 / 300`
- 字数进度：`7.2 万 / 80 万`
- 知识库模式：手动 / 确认 / 自动
- 最近编辑章节
- 更新时间
- 操作：打开、复制、归档、删除

### 新建工程弹窗

第一步：基础信息

- 标题
- 类型
- 一句话创意
- 目标总字数
- 目标章节数
- 每章字数
- 卷数

第二步：风格

- 叙事视角
- 文风
- 平台风格
- 禁忌与雷区

第三步：初始化方式

- 空白工程
- AI 生成创作蓝图
- 从已有文本导入

## 页面二：小说创作工作台

文件建议：

- `web/src/views/NovelWorkspace.vue`

## 工作台整体布局

推荐使用四区布局：

```
┌────────────────────────────────────────────────────────────────────┐
│ 顶部栏：小说名 / 当前章节 / 保存状态 / 生成 / 审稿 / 图谱入口        │
├───────────────┬──────────────────────────────────────┬─────────────┤
│ 左侧栏         │ 中央写作区                            │ 右侧栏       │
│ 大纲 / 章节    │ Markdown 编辑器 + AI 生成结果           │ 上下文/版本   │
│               │                                      │             │
├───────────────┴──────────────────────────────────────┴─────────────┤
│ 底部状态栏：字数 / 目标字数 / 当前知识库模式 / 最近图谱更新          │
└────────────────────────────────────────────────────────────────────┘
```

建议尺寸：

- 左侧栏：280-340px，可收起。
- 右侧栏：340-420px，可收起。
- 中央区域：自适应，优先保证编辑器宽度。
- 底部状态栏：32-40px。

## 顶部栏

内容：

- 返回工程列表
- 小说标题
- 当前章节标题
- 保存状态：已保存 / 未保存 / 保存中 / 保存失败
- 当前模式：写作 / 图谱 / 审稿
- 主要操作：
  - 保存
  - 生成版本
  - 审稿
  - 提取图谱
  - 转入文本库

交互：

- 保存按钮在有未保存内容时高亮。
- 生成按钮打开右侧生成面板或直接运行当前配置。
- 图谱入口切换到图谱工作区。

## 中央写作区

组件建议：

- `NovelChapterEditor.vue`

### 编辑器布局

```
┌─────────────────────────────────────────────┐
│ 章节标题输入                                 │
├─────────────────────────────────────────────┤
│ Markdown 工具栏：标题 / 粗体 / 引用 / 分割线 │
├─────────────────────────────────────────────┤
│ Markdown 正文编辑器                          │
├─────────────────────────────────────────────┤
│ AI 生成结果预览 / 差异对比 / 插入操作         │
└─────────────────────────────────────────────┘
```

### 编辑器要求

- Markdown 输入。
- 字数统计。
- 目标字数进度。
- 自动保存草稿。
- 手动保存。
- 支持撤销/重做。
- 支持从光标处续写。
- 支持选中文本后改写。

### AI 生成结果区

生成后不要直接覆盖正文，先展示结果。

操作：

- 采纳为正文
- 插入到光标处
- 替换选中内容
- 另存为版本
- 继续基于该版本改写
- 丢弃

### 多版本对比

当生成多个版本时，中间区域可切换为版本对比视图：

```
┌─────────────┬─────────────┬─────────────┐
│ 稳健推进版   │ 强冲突版     │ 悬疑反转版   │
│ 正文预览     │ 正文预览     │ 正文预览     │
│ 采纳按钮     │ 采纳按钮     │ 采纳按钮     │
└─────────────┴─────────────┴─────────────┘
```

移动端或窄屏使用单列版本卡片。

## 创作蓝图向导

组件建议：

- `NovelBlueprintWizard.vue`

用途：

- 从一句创意生成整本书蓝图。

步骤：

1. 输入创意、类型、目标字数。
2. 设置主角偏好、文风、平台风格。
3. AI 生成世界观、人物、主线。
4. 用户确认或修改。
5. AI 生成卷大纲和章节目录。
6. 写入工程。

## 视觉风格建议

该模块是创作生产工具，应保持安静、清晰、耐久：

- 避免营销式 hero。
- 避免大面积装饰图。
- 工具栏、面板、列表要紧凑。
- 图谱节点要有类型区分，但不要颜色过载。
- 编辑器区域优先保证阅读和写作舒适度。
- 卡片仅用于版本、候选项、实体摘要，不要层层套卡。
